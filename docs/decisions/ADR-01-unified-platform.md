# ADR-01 — Unified platform, not separate event/OJT products

Status: Accepted. Context: CICT-QR + OJT-Qr-Pass overlap but diverge. Decision: one shared attendance engine + configurable policies/sessions; event/OJT/shift/class/visitor as session types. Consequences: single domain to harden; requires policy flexibility. Refs: overview.md, attendance-state-machine.md.
